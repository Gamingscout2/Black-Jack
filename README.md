## Black-Jack
This repository is for my experiments with implementing Black Jack!
Right now, there is a C++ development branch and a C development branch.

**C** The C branch is designed to be a "bitwise" version of the game, where the entire deck
is stored as an integer, and bitwise operations modify decks and hands. This is hard to code,
but very light on the device it runs on. For super-high performance, and primarily for my education
and practice.

**C++** The C++ branch is a much more traditional implementation, aimed at using the std:vector data 
type to use dynamic arrays. The goal here is to teach myself a different data structure in C++!

The MIT license is used for this repository, feel free to use this code in whatever you want! This
repository is for my educationa and amusement.
